# Log Note

一个移动端优先、本地优先的快速记录 Demo。点击右下角的“记录”按钮即可写下一条带时间、分类和标签的记录，不需要登录或联网。

## 启动

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3100](http://localhost:3100)。生产模式：

```bash
npm run build
npm start
```

## 已支持

- 按日期浏览当天时间线，自动填入当前时间。
- 新增、编辑和删除记录。
- 全局搜索内容、分类和标签。
- 首页只保留日期、记录时间线和固定加号，减少非必要信息。
- 记录页支持自由文本，以及文字、多行、数字、选项和 1–5 评分等结构化字段。
- “万能记录”模板内置内容、状态和下一步，选择后可以直接点选和填写。
- 记录面板默认只显示当前模板字段；分类、标签和时间按需展开。
- 自定义分类；使用 `父级 · 子级` 命名可生成多级 Markdown 标题。
- `/templates` 是独立模板管理页，可增删字段、切换字段类型并设置必填项。
- 首次打开会载入 `2026_08_11.md` 中的 18 条实际记录作为测试数据，原始日记文件不会被修改。
- 导出单日 Markdown、全部 Markdown 和完整 JSON 备份。
- 从 JSON 恢复分类、模板和全部记录。
- PWA manifest、离线缓存和添加到主屏幕。

## 数据说明

数据保存在当前浏览器的 `localStorage` 中，不会上传到服务器。清除浏览器数据、切换浏览器或切换域名/端口都会形成不同的数据空间，请定期在“导出与备份”中下载 JSON 备份。

Markdown 单日文件按分类生成，例如：

```md
## 日常记录

- 08:28 出发上班 #通勤

## 健康

### 饮食节奏

- 12:20 午餐：南瓜粥 #饮食
```

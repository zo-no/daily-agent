# Reflect

本目录只记录 Agent 在执行任务时遇到的使用反馈。

这里的内容：

- 不是产品需求；
- 不是技术规范；
- 不是当前任务；
- 不是实现依据；
- 不得自动转化为代码、配置或流程变更。

Agent 可以记录写代码、写文档、阅读项目或执行验证时遇到的不便。只有项目负责人明确
审阅并批准后，反馈才可以转化为对 `AGENTS.md`、编码规范、产品/架构文档的修改，或新的
任务/改进项。

反馈尽量记录：

- 发生场景；
- 当前不方便之处；
- 造成的具体影响；
- 建议的改进方向；
- 是否需要负责人判断。

反馈文件建议使用日期和主题命名，例如：

```text
Reflect/2026-09-05-agent-editing-feedback.md
```

# Log Note 设计规范 Index

> 本文件只负责路由、阅读顺序和规则优先级，不重复维护正式规则正文。

## 使用方式

开始设计、编码或 QA 前，先阅读根目录 `DESIGN.md`，再按当前问题进入一到两份专项规范。

| 问题 | 正式入口 |
| --- | --- |
| 字体、颜色、间距、表面和密度 | [视觉系统规范](规范/基础/视觉系统规范.md) |
| 拖拽、排序、跨组移动和无障碍 | [拖拽与排序交互规范](规范/交互/拖拽与排序交互规范.md) |
| 动效、状态和操作反馈 | [反馈与动效规范](规范/交互/反馈与动效规范.md) |
| 层级列表、拖拽行、菜单和编辑抽屉 | [层级列表与编辑抽屉规范](规范/组件/层级列表与编辑抽屉规范.md) |
| 记录页或结构管理页整体流程 | [记录与结构管理页面规范](规范/页面/记录与结构管理页面规范.md) |
| 领域趋势、来源复盘与投资记录边界 | [领域复盘页面规范](规范/页面/领域复盘页面规范.md) |

## 文档分层

| 目录 | 职责 |
| --- | --- |
| `规范/` | 正式规则和验收条件 |
| `指南/` | 如何新增、修改和 Review 规范 |
| `模板/` | 新规范的可复制骨架 |
| `调研/` | 社区证据、取舍和参考链接 |
| `scripts/` | 结构和链接自动校验 |

## 规则优先级

```text
用户对当前任务的明确决定
> DESIGN.md 与匹配的正式规范
> 本 Index 的路由说明
> 指南、模板和调研材料
```

发生冲突时先标记并消除双重事实源，不依赖优先级长期掩盖冲突。

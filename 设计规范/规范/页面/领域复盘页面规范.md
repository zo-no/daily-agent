# 领域复盘页面规范

## 目标

把当前账号最近一段时间的记录转换为可核对、可离线使用的领域活动回顾，同时让快速记录、原始正文、账号隔离、同步与备份保持不变。首版是次级、只读、可移除的本地工具，不是远程 AI、投资顾问或持久化画像系统。

## 名词解释

| 名词 | 定义 |
| --- | --- |
| 领域复盘 | 从当前账号本地 payload 临时推导的 30 天领域活动与来源证据；不写回任何派生结论。 |
| 当前领域 | 移动端目录中由现有滚动定位规则标记为 `aria-current` 的一个领域。 |
| 证据状态 | `empty`、`insufficient` 或 `ready`；少于 3 条合格记录或少于 2 个活跃日时不得描述趋势。 |
| 投资类领域 | 仅由领域可见名称匹配“投资、交易、理财、金融、investment、trading、finance”的有限集合。 |

## 正式规则

### 入口与导航

- MUST 只在移动端当前领域旁显示一个独立复盘链接，并让原领域目录按钮继续只负责滚动定位。两个真实目标都不得小于 `44 × 44px`，边界之间 MUST 保持至少 `4px`，且不得覆盖领域文字、装订轴、正文、顶部工具或底部操作。
- MUST 使用项目内真实透明石墨 PNG 作为复盘图标，不得使用 emoji、文字符号、CSS 图形、内联 SVG 或占位框。可访问名称 MUST 包含当前领域名，键盘焦点必须清晰。
- MUST 让移动入口随当前领域移动，而不是在每个领域旁重复。桌面 MAY 在页头提供一个紧凑次级入口；该入口在移动端必须隐藏，不能改变“搜索 → 设置 → 时间/分类 → 日记/计划”的既有顺序。
- MUST 让领域入口一次导航到 `/insights?domain=<id>`；未知或已删除的 `domain` MUST 安全回退到最近有记录的第一个领域，再回退到第一个现有领域。页面必须提供一次返回记录页的明确动作。

### 内容与视觉层级

- MUST 以当前本地日期及前 29 个自然日组成固定、含首尾的 30 点窗口。每个领域展示记录数、活跃日、普通/周期记录拆分、每日折线、证据状态、趋势文字、至多 3 条近期来源和必要的未归属记录说明。
- MUST 将复盘页表现为与日记同源的开放纸面报告：Serif 负责页面与领域标题，Sans 负责正文，Mono 负责日期和数字；使用留白、细弱横线与一条克制蓝色活动线表达结构。不得把指标、折线、来源或提示堆成通用卡片墙，不得增加渐变、厚阴影、第二强调色或大圆角装饰。
- MUST 让领域选择态和趋势方向同时通过文字、语义状态或形状表达，不能只依赖颜色。所有切换、返回和来源链接目标不得小于 `44px`，320/390/426/768/1280px 不得横向溢出或裁切必要标签。
- MUST 用真实数据动态绘制 30 点折线。Canvas 必须提供包含领域、窗口和总量的语义名称，并在画布外显示等价的起点、中点、终点文字摘要；颜色不得是理解趋势的唯一方式。
- SHOULD 把结论写成“记录活动比前一段更多 / 更少 / 接近”，不得把记录频率直接解释为健康、能力、情绪、收益、纪律或生活质量。证据不足时只显示已有事实和继续记录提示。

### 来源、隐私与账户边界

- MUST 让每个可见结论可回到当前账号内的真实来源记录；来源摘录只用于显示，长度受限，不得写回、替换、翻译或扩充原文。
- MUST 在内存中从当前账号已 hydration 的本地 payload 推导全部结果。账号切换、恢复保护或 payload 替换时必须丢弃旧结果；恢复保护期间不得分析临时默认数据。
- MUST_NOT 持久化派生指标、提示或摘录，不得修改记录、计划、结构、设置、revision、附件、同步文档、Markdown、JSON 或便携备份。
- MUST_NOT 发起市场、AI、分析遥测或其他外部请求。已认证设备离线时，`/insights`、本地图标、当前账号隔离缓存和返回路径必须继续可用。

### 投资记录边界

- MAY 对投资类领域显示“决策理由 / 结果回看 / 风险边界”三项关键词覆盖数量，并选择覆盖最少的一项作为下一次记录提示。该覆盖只描述记录是否包含有限线索，不代表事实判断、投资表现或风险画像。
- MUST 在投资类领域的 `empty`、`insufficient` 与 `ready` 三种状态都持续显示“仅复盘记录，不构成投资建议”的清晰边界，并让提示链接到实际来源。
- MUST_NOT 生成或暗示买入、卖出、持有、标的、价格目标、时机、仓位、资产配置、预期收益、盈亏判断、个性化风险承受能力或市场预测。

### 状态与反馈

- MUST 为 hydration、账号切换、恢复保护、无领域、空领域、证据不足和可分析状态提供可理解文案；不得短暂显示上一账号结论、空白页面、假加载进度或负面评判。
- MUST 遵守 `prefers-reduced-motion`。折线重绘、领域选择和焦点反馈不得推动页面或循环表演；非必要过渡应立即或在 `140–180ms` 内完成。

## 验收

- 390px 当前领域只出现一个独立复盘入口；滚动到另一领域后入口随之移动，目录按钮仍可滚动，两个目标均不少于 `44px` 且相距至少 `4px`。
- `/insights` 在 320/390/426/768/1280px 无横向溢出，所有必要文字、30 点折线替代摘要、来源日期、键盘焦点和中英文长领域名可读。
- 固定 fixture 的领域总数、活跃日、普通/周期拆分、未归属桶、30 点序列及最近来源逐项对账；同一记录只计入一个领域或未归属桶。
- 少于 3 条记录或少于 2 个活跃日只显示证据不足；投资类 fixture 只出现三项记录覆盖、一个记录提示和非建议声明，不出现交易、标的、价格、时机、仓位或收益建议。
- 打开、切换领域、返回、离线直达和账号替换前后，本地 source payload 字节等价；页面无市场、AI、遥测或其他外部请求。
- 5,000 条记录的纯推导与首屏渲染在既有 390 × 844 Chromium 验收环境中不超过 1 秒。

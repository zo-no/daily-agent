# 反馈与动效规范

## 正式规则

- MUST 让动效解释状态变化，不承担装饰或页面表演。
- MUST 遵守 `prefers-reduced-motion`，将非必要动效降到近乎即时。
- SHOULD 使用 140–180ms 处理 hover、focus 和简单状态切换。
- 右轨双模式拨杆 MAY 在 `140–180ms` 内让抬起纸片沿单一轴移动到另一端，并同步完成当前/未选文字的墨色变化；不得弹跳、过冲、旋转或移动外层按钮。`prefers-reduced-motion` 下纸片与文字必须在不超过 `10ms` 内直接进入最终状态。
- SHOULD 使用 180–240ms 处理拖拽升起、排序位移和落位。
- 首页右侧区块目录 SHOULD 在对应标题仍位于可读区时以约 `180ms` 平滑跟随标题 Y 轴；越界标题的节点按正文顺序收拢到上/下边缘，MUST_NOT 交叉、弹跳或随滚动抖动。空间无法容纳完整命中区时改为目录内部滚动。`prefers-reduced-motion` 下节点位置立即更新。
- 首页时间记录与固定记录获得键盘或输入焦点时，SHOULD 用约 `200ms` 的左到右裁切显露完整蓝色手绘圈线；失焦后克制消退。圈线不得造成行高变化、正文位移或循环动效，`prefers-reduced-motion` 下直接显示/隐藏最终状态。
- SHOULD 在拖拽时只增加轻微阴影、位移和透明度变化。
- 日期导航横向滑动 MUST 使用覆盖完整 viewport、但深色视觉范围在边缘 `min(44vw, 420px)` 内衰减完毕的线性方向阴影；向右拖时左边缘最深并向右透明，向左拖时镜像。阴影与日期铭牌 MUST 使用温暖、半透明的石墨灰，MUST_NOT 使用纯黑或视觉上接近死黑的反馈。MUST 同时显示一个高度 `44–52px`、宽度随内容克制增长的圆角日期铭牌，完整承载本地化目标年、月、日；左滑时铭牌固定在 viewport 中轴左侧一个 `min(12vw, 56px)` 步长处，右滑时镜像到右侧，纵向仍固定居中。铭牌可用约 `150ms`、无位移和无弹跳的透明度加 `0.88 → 1` 缩放解释横向意图，但不得跟随手指、吸附标题、显示箭头或引发页面位移。除该铭牌外，不得渲染手柄、额外胶囊、楔形幕布或其他方向组件。页面、顶栏、日期、正文和浮动操作不得位移、缩放或交叉淡化。松手时最终水平位移 MUST 严格超过 viewport 宽度的 `20%` 才切换日期或月份，不得用速度或快速甩动绕过距离阈值；即使中途超过阈值，只要最终回撤到 `20%` 或以内就 MUST 取消。取消时阴影与铭牌应在约 `120ms` 内同步回收；切换时应在约 `175ms` 内完成更新与消退。两者不得阻断纵向滚动、点击按钮及键盘路径，reduced-motion 下必须取消铭牌动画且不得改变阴影、铭牌或页面几何。
- MUST 用 toast 或 live region 确认需要用户知道的保存、导出和排序结果。
- MUST_NOT 用循环动画、弹跳或大范围页面过渡干扰快速记录。
- 首页日记内容 MAY 在真实页面进入时使用一次克制的透明度与轻微纵向归位，总时长不得超过 `240ms`；滚动、日期切换和视图切换不得反复播放为装饰。`prefers-reduced-motion` 下 MUST 取消该进入动画。
- 普通记录编辑器 MAY 用一次短距离纸页抬起解释“从日记进入书写”，遮罩只允许轻微淡入；不得弹跳、过冲、缩放正文或延迟输入焦点。关闭与 `Done` 必须即时响应，快速连续记录不得等待退场动画；`prefers-reduced-motion` 下纸页与遮罩直接进入最终状态。
- 普通记录编辑器展开“更多”时 MAY 用不超过 `160ms` 的透明度与不超过 `5px` 纵向归位解释账页出现；不得让正文、工具栏或危险操作弹跳，也不得延迟输入、保存、附件或删除确认。正文高度变化与页边焦点墨线在 `prefers-reduced-motion` 下 MUST 直接进入最终状态。
- 日记 Agent 必须通过同一挂载点解析 `idle/scanning/reviewing/complete` 四个独立本地形象状态，并在有普通记录的 Diary 中持续可见。扫描态 MAY 在普通记录与固定记录之间的专属活动区内进行克制往返；审查态 MAY 在右半区使用轻微呼吸位移，但不得覆盖来源记录、行内批注、固定字段、领域目录或 Diary/Plan/导出/新增操作；完成态停回装订边。进入具体问题后不得再隐藏形象，也不得绘制蓝色路径、虚线或长下划线；来源关系仍由记录后紧邻批注、`aria-current` 与短局部笔触表达，键盘焦点继续独占完整手绘圈。所有运动不得推动正文或右轨；`prefers-reduced-motion` 下必须取消运行中动画并直接显示各状态的确定静态位置。形象状态与位置不得写入账号数据、网络请求或备份格式。
- 日记 Agent 的 LN-076 Rework 8 动效取代上一条的内容区往返范围：移动端 `320–700px` 把整体慢巡游与角色局部动作分开。沿用旧形象的 6 帧透明 APNG 在一个动作周期内表现“抓住 → 向上/下换握点 → 身体收紧跟上 → 停稳”，眼睛只在观察与换握时做 1–2px 方向变化；`idle` 局部周期约 3 秒，`scanning` 约 2.4 秒并以探出/收回表达扫视，`reviewing` 约 4 秒且保留手抵下巴的思考姿势、视线在来源记录与批注之间缓慢移动，`complete` 约 3 秒完成盘身、舒展和再抓握。外层 traveler 仍沿视口安全书脊段移动，必须读作贴着书脊缓慢攀爬而非漂浮：`idle` 为 28 秒单程并在抓握点分段停顿，`scanning` 为 20 秒单程，`reviewing` 为 32 秒且移动范围约缩为普通巡游的三分之一，`complete` 短暂放松后使用 30 秒回程巡游。桌面端不巡游。展开月历时回到安全紧凑姿势；按钮聚焦、指针按住、页面后台化时暂停在当前位置；`prefers-reduced-motion` 下完全静止。角色与真实按钮必须同步移动，右轨控件始终更高且可点击，动画不得推动正文、触发网络、写入数据或在后台继续运行。
- 日记 Agent 的明示操作 MUST 有可见结果：分类建议已与记录最新分类相同时，展示前应直接过滤；若展示后才变为相同，点击应明确反馈“已经属于该分类”并继续下一条，不进行无意义写入。可用按钮 MUST_NOT 静默返回并留在原批注。

## 验收

- 快速连续记录不会被动效阻塞。
- 拖拽中的源位置、浮层和目标位置可以明确区分。
- 屏幕阅读器播报使用人类可理解的名称，不播报内部 ID 或零基索引。

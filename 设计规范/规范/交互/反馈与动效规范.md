# 反馈与动效规范

## 正式规则

- MUST 让动效解释状态变化，不承担装饰或页面表演。
- MUST 遵守 `prefers-reduced-motion`，将非必要动效降到近乎即时。
- SHOULD 使用 140–180ms 处理 hover、focus 和简单状态切换。
- SHOULD 使用 180–240ms 处理拖拽升起、排序位移和落位。
- SHOULD 在拖拽时只增加轻微阴影、位移和透明度变化。
- 日期导航横向滑动 MUST 使用覆盖完整 viewport、但深色视觉范围在边缘 `min(44vw, 420px)` 内衰减完毕的线性方向阴影；向右拖时左边缘最深并向右透明，向左拖时镜像。阴影与日期铭牌 MUST 使用温暖、半透明的石墨灰，MUST_NOT 使用纯黑或视觉上接近死黑的反馈。MUST 同时显示一个高度 `44–52px`、宽度随内容克制增长的圆角日期铭牌，完整承载本地化目标年、月、日；左滑时铭牌固定在 viewport 中轴左侧一个 `min(12vw, 56px)` 步长处，右滑时镜像到右侧，纵向仍固定居中。铭牌可用约 `150ms`、无位移和无弹跳的透明度加 `0.88 → 1` 缩放解释横向意图，但不得跟随手指、吸附标题、显示箭头或引发页面位移。除该铭牌外，不得渲染手柄、额外胶囊、楔形幕布或其他方向组件。页面、顶栏、日期、正文和浮动操作不得位移、缩放或交叉淡化。松手时最终水平位移 MUST 严格超过 viewport 宽度的 `20%` 才切换日期或月份，不得用速度或快速甩动绕过距离阈值；即使中途超过阈值，只要最终回撤到 `20%` 或以内就 MUST 取消。取消时阴影与铭牌应在约 `120ms` 内同步回收；切换时应在约 `175ms` 内完成更新与消退。两者不得阻断纵向滚动、点击按钮及键盘路径，reduced-motion 下必须取消铭牌动画且不得改变阴影、铭牌或页面几何。
- MUST 用 toast 或 live region 确认需要用户知道的保存、导出和排序结果。
- MUST_NOT 用循环动画、弹跳或大范围页面过渡干扰快速记录。

## 验收

- 快速连续记录不会被动效阻塞。
- 拖拽中的源位置、浮层和目标位置可以明确区分。
- 屏幕阅读器播报使用人类可理解的名称，不播报内部 ID 或零基索引。

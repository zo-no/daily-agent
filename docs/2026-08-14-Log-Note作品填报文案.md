## 作品详情

```markdown
# Log Note｜个人 Agent OS

> 把人生运行成可理解、可验证、可持续优化的 Log。

我们每天都在产生大量关于时间、行动、状态、目标与结果的信息，但它们散落在笔记、日历、待办、健康 App 和各类系统里。它们被保存了，却很少真正反过来帮助我们理解自己、调整行动。

Log Note 想做的不是另一个笔记工具，而是一套以 **Universal Log** 为数据底座的个人 Agent OS。

## 核心思路

### 1. All in one：把一切系统 Log 日志化

All in one 不是把所有功能堆到同一个首页，而是让不同来源的信息最终进入同一套可追溯的 Log 模型：

- 一段自然语言日记
- 一次工作或学习活动
- 一条柳比歇夫式时间记录
- 一次睡眠、运动或身体状态记录
- 一个目标、计划或实际执行动作
- 一项结果、反馈或复盘结论
- 经用户授权导入的数字活动

无论数据来自哪里，都可以沿着同一条个人时间线被搜索、理解、关联和验证。

### 2. 柳比歇夫时间日记：先记录真实发生的时间

产品吸收柳比歇夫时间统计法的核心思想：长期记录时间实际花在了哪里，用事实校准自我认知，而不是只管理计划。

时间不是孤立的统计数字，它可以继续与当时的精力、情绪、环境、行为和结果建立关联。

### 3. AI 是语义编译层

用户继续用自然语言低成本记录，AI 在背后把内容转化为可计算的事件、状态、目标、结果和已有标签。

AI 不会静默改写原文。所有标签、摘要、趋势、关联和假设都是独立的派生数据，并且必须：

- 引用对应的原始 Log
- 区分事实、相关性和待验证假设
- 可以纠正、撤销、删除和重新计算
- 在证据不足时明确表示“不知道”

### 4. 多个领域 Agent，由主 Agent 协调

健康、学习、工作、生活和时间问题需要不同的观察视角，因此 Log Note 采用多 Agent 架构：

- **时间 Agent**：理解时间投入、节奏、计划与实际偏差
- **健康 Agent**：理解睡眠、饮食、运动和身体反馈
- **学习 Agent**：理解学习投入、练习、输出和掌握情况
- **工作 Agent**：理解项目进展、深度工作、阻塞和交付
- **生活 Agent**：理解情绪、关系、恢复与日常事件
- **主 Agent**：结合用户目标和现实约束，协调各领域 Agent 的观察与建议

领域 Agent 默认只读。任何提醒、日程、待办或外部系统操作，都必须经过逐领域、逐能力授权，并且可以暂停、撤销和审计。

### 5. 拟合属于每个人自己的优秀 Log 曲线

Log Note 不使用平台统一标准评价“优秀人生”。

优秀曲线指的是：在用户自己的目标、资源和现实约束下，更稳定地产生期望结果、且代价可以接受的轨迹。

产品通过下面的闭环逐渐理解什么对这个用户真正有效：

```text
记录 → 分析 → 发现关键变量 → 微型干预 → 验证结果 → 更新理解
```

例如，系统发现午餐较重与下午低精力经常同时出现时，不会直接宣称因果关系，而是建议用户进行一个 3–7 天的小实验，最后比较执行、结果、成本和副作用。

最值得优先参考的“优秀曲线”，不是陌生人的成功模板，而是用户自己的历史最佳状态。

## 当前已完成的 MVP

目前 Log Note 已完成一个可演示的、本地优先、移动优先记录底座：

- 普通记录的新增、浏览、搜索、编辑和删除
- 日期时间线与领域/分类视图
- 领域、分类、模板与周期记录
- 自由文本、结构化字段与基础 Markdown
- 本地图片附件
- 完整 JSON 备份与安全恢复
- 可读 Markdown 导出与便携附件备份
- PWA 安装、离线记录和刷新后持久化
- 无账号、无服务端数据库、无默认数据上传

## 下一阶段

AI、多 Agent 和曲线拟合目前是下一阶段产品方向，尚未作为已上线能力进行宣传。

第一步不会直接实现全自动 Agent，而是验证一个最小反馈闭环：

1. 用户连续记录 14 天
2. AI 从用户已有标签中进行语义匹配
3. 生成一个带原始 Log 引用的“当前轨迹”观察
4. 只提出一个可验证的微型调整
5. 用户决定是否进行 3–7 天实验
6. 实验结束后比较真实结果

只有当这个闭环真正对用户有用，才会逐步开放多领域 Agent、提醒、日程和有限自动执行。

## 产品原则

- 真实记录比完整记录更重要
- 首页首先服务快速记录
- 原始 Log 永远不被 AI 静默修改
- AI 观察必须能够追溯证据
- 相关性不能包装成因果关系
- 优化目标由用户定义
- Agent 默认只读，执行必须授权
- 所有派生信息与自动动作都可撤销、暂停和回顾
- 无网络、无账号、无 API Key 时，核心记录功能仍然完整可用

## 一句话总结

**Log Note 记录你正在如何生活，让 AI 和多个 Agent 帮你理解当前轨迹，并通过真实验证找到更适合你的下一步。**

# LN-035 本地报告下载 API 验证说明

## 边界

`POST /api/reports/download` 是无状态、同源的本地报告生成边界。调用方必须显式提交测试夹具或当前 state；服务端不读取浏览器 `localStorage`，不保存请求，不上传数据，也不改变现有客户端离线导出。

- 请求体上限：1 MiB，按流累计；超过后立即取消读取并返回 `413 REPORT_BODY_TOO_LARGE`。
- 生成结果上限：2 MiB UTF-8；Markdown 在调用现有生成器前做保守预算检查，所有类型生成后再精确检查。
- 成功响应：受控 `Content-Type`、`Content-Disposition`、UTF-8 `Content-Length`、`Cache-Control: private, no-store`、`X-Content-Type-Options: nosniff`。
- Service Worker 跳过所有 `/api/*` 请求；PWA 回归会确认报告 API 未进入 Cache Storage。

## 合成夹具

[`tests/fixtures/report-api-state.json`](../tests/fixtures/report-api-state.json) 仅用于下面的本地 curl 验证。它包含两条合成记录，不含真实用户数据。

## 真实 HTTP 验证

先构建并启动独立端口：

```sh
npm run build
./node_modules/.bin/next start -p 3111
```

成功 Markdown 附件：

```sh
jq -n --slurpfile state tests/fixtures/report-api-state.json \
  '{kind:"markdown",scope:"range",startDate:"2026-08-10",endDate:"2026-08-12",state:$state[0]}' \
  | curl -i -H 'Content-Type: application/json' -H 'Origin: http://localhost:3111' \
      --data-binary @- http://localhost:3111/api/reports/download
```

完整备份、GET 405、跨源与请求超限：

```sh
jq -n --slurpfile state tests/fixtures/report-api-state.json \
  '{kind:"backup-json",scope:"all",state:$state[0]}' \
  | curl -i -H 'Content-Type: application/json' --data-binary @- \
      http://localhost:3111/api/reports/download

curl -i http://localhost:3111/api/reports/download

curl -i -H 'Content-Type: application/json' -H 'Origin: https://example.com' \
  --data '{}' http://localhost:3111/api/reports/download

curl -i -H 'Content-Type: application/json' -H 'Content-Length: 1048577' \
  --data '{}' http://localhost:3111/api/reports/download
```

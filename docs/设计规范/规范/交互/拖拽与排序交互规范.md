# 拖拽与排序交互规范

## 适用对象

领域、分类、模板和模板字段的排序与父级变更。

## 正式规则

- MUST 使用独立、可聚焦、带名称的六点拖拽把手。
- MUST 支持鼠标、触摸和键盘；Enter/Space 拾取与放下，方向键移动，Escape 取消。
- MUST 提供 Move up、Move down，以及跨父组对象的 Move to… 备用操作。
- MUST 在移动后压缩受影响父组的 `order` 为连续的 `0..n-1`。
- MUST 让空领域接收分类、空分类接收模板。
- MUST 在模板跨分类后同步更新使用该模板的历史记录分类，但不得修改记录正文、ID 和来源。
- MUST_NOT 在原位置放下或取消拖拽时写入状态。
- SHOULD 让触摸拖拽延迟约 180ms，并设置移动容差，避免抢占页面滚动。
- SHOULD 保持移动条目的键盘焦点，并用当前语言播报拾取、移动、放下和取消。

## 验收

- 指针可在同组和跨组完成移动。
- 空目标组有可感知的放置区域。
- 键盘和菜单路径能完成所有指针路径的结果。
- 刷新后父级与顺序保持，Markdown 导出采用新顺序。

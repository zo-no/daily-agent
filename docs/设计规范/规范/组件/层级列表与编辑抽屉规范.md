# 层级列表与编辑抽屉规范

## 层级列表

- MUST 使用缩进和一条细竖线表达父子关系。
- MUST 让整行主要区域进入编辑，把手只负责拖拽，更多菜单只负责排序备用动作。
- MUST 在一行中只保留名称、必要的数量或类型信息和操作入口。
- SHOULD 让领域标题使用衬线字体，分类使用 UI 字体，模板名称使用较小的编辑字体。
- MUST_NOT 在空组同时出现多个新建入口；空组只保留放置提示，创建入口放在组标题或父级行。

## 编辑抽屉

- MUST 在桌面从右侧出现，在移动端占满宽度。
- MUST 保持名称、归属、记录行为、输入结构、默认值和删除操作的固定阅读顺序。
- MUST 允许周期记录和模板字段编辑，不得把内置模板视为只读数据。
- SHOULD 将少用的默认标签和预填文字放入可展开区域。
- SHOULD 让自动保存状态安静可见，不与标题或关闭操作竞争。

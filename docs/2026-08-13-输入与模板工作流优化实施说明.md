# Log Note 输入与模板工作流优化实施说明

## 为什么做

本轮针对两个直接影响主线的问题：记录输入不够安全、模板编辑和导出无法帮助用户理解最终记录效果。快速记录仍保持“打开后直接输入，点击完成保存”，没有增加首页入口或普通记录必填项。

## 调度与审计方式

总控先读取项目看板、设计规范和现有实现，再并行调度两个只读子 Agent：一个审计记录输入，一个审计模板编辑、预设与导出。主工作区始终只有总控一个写入者，避免覆盖已有未提交改动。

审计确认的核心问题：模板切换会清空字段草稿；关闭弹层会直接丢未保存内容；已有结构化记录重开后退化为纯文本；结构化和单值模板的 prompt 没有显示；模板只能从空白创建；导出把记录、备份、结构示例混在同一层；通用示例没有覆盖主要模式。

## 具体改动

### 输入体验

- 新建记录时按模板缓存草稿。自由文本、结构化表单之间往返会恢复各自内容，不再静默丢失。
- 非空新记录或已修改记录关闭时询问是否放弃；空草稿和未改编辑可直接关闭。
- 已保存的结构化记录在模板仍兼容时按原字段重新编辑；旧记录或模板字段不兼容时继续使用全文安全编辑，避免猜测拆分和丢历史正文。
- 结构化和单值模板显示自己的输入指导；单值输入同时使用 prompt 作为输入示例。
- `Cmd/Ctrl + Enter` 可保存；必填失败后聚焦首个缺失字段。
- 结构化字段补充 label 关联、按钮选中态和分组语义；弹层支持 Escape、焦点圈定和关闭后焦点恢复。

### 模板编辑与预设

- 新建模板提供三个起点：随手记、结构化复盘、每日单值。它们只生成可编辑初值，不把更多模板强行注入旧数据。
- 模板可复制，复制后字段 ID 独立，不影响原模板。
- 编辑抽屉加入“记录时预览”，随输入模式、prompt、字段、选项和周期值即时变化。
- 保留自动保存和已有高级默认项，避免引入额外保存步骤。

### 导出与通用示例

- 导出分为“可阅读记录”“可恢复备份”“结构与起步示例”三组。
- 当前结构文件带日期，通用示例使用稳定版本名；说明明确结构示例不含记录、不能冒充完整备份。
- 通用示例覆盖 free、structured、value 三种输入模式；text、textarea、number、select、rating 五种字段；daily、weekly、timepoint 三种周期。
- `docs/log-note-structure-template.json` 与运行时导出的示例同步更新。

## 明确未做

- 没有增加结构导入，因为“替换还是合并、已有记录如何迁移”需要独立的数据安全设计与用户确认。
- 没有触碰账号、同步、AI、服务端或数据出设备。
- 没有提交、推送或清理工作区中的其他改动。

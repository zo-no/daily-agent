# LN-030 固定记录与结构管理体验实施说明

## 改善的核心行为

本轮减少首页首屏的并列管理信息，让阅读顺序回到“快速新增 → 当天内容 → 固定记录”，同时让固定记录的调整、暂停和恢复都有可发现入口。普通快速记录的打开、输入和保存步骤没有增加。

## 实现范围

- 固定记录移到时间线或分类分组内容之后，并减少时间线、分组和固定记录中的行级重复横线。
- 固定记录标题加入低权重“调整”入口，进入只突出周期记录的结构管理视图；全部暂停后入口仍保留。
- 原“领域与分类 / 模板”双视图合并为一棵领域 → 分类 → 记录方式连续树。三类对象的数据、归属、排序与编辑语义仍独立。
- 周期记录新增可选 `homeVisible` 状态。字段缺失默认显示；暂停只隐藏首页入口，不删除设置、历史正文或模板关联。
- 桌面编辑器加宽并强化固定阅读顺序、留白和状态；移动端保留自动保存状态，关键结构操作提供至少 44px 触控区，并为软键盘场景增加 sticky 页头与滚动余量。
- 中英文界面使用“怎样记录、直接写一段、分项填写、观察与下一步、普通记录、固定记录”等动作/结果语言，内部数据字段名称不变。
- `generalStructureTemplate()` 下载的是面向开发者手工编辑的 JSON 起步示例，其中保留 `Structured reflection` 等示例数据名称；它不作为界面标签展示，也不改变任何已有用户模板名称。

## 数据与恢复边界

- 不提升数据或结构 schema 版本，不批量迁移现有模板。
- `homeVisible !== false` 即显示，旧备份和旧本地数据自然兼容。
- 完整 JSON 和结构 JSON 都保留暂停状态；Markdown 输出、历史正文、模板与记录关联不受暂停影响。
- 删除、复制、排序、跨父级移动、周期配置和字段编辑继续使用原数据操作路径。

## 验证

- 单测覆盖缺失状态默认显示、完整备份往返、结构 JSON 往返与历史正文不变。
- E2E 覆盖首页新阅读顺序、连续结构树排序、固定记录调整入口、暂停与恢复。
- 最终移动端 320/390 与 320×500 软键盘验收仍由 LN-031 / P01-T09 独立执行。

## 隔离与退出条件

显示状态只附着于周期记录模板并只影响首页筛选，可随时恢复，也可以在后续移除该控制而不改写原始记录。如果真实使用表明“调整”入口不被理解、暂停导致遗漏或结构树降低维护效率，应保持该能力在二级管理页或回退界面呈现，不能把额外决定加入快速记录路径。
